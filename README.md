# vibe-starter

A one-page website with **no build step** — the clone target for the
[Set up your machine for vibe coding](https://napjose.ph/writing/vibe-coding-machine)
series.

- `index.html` is the entire project. Open it in any browser.
- The `<h1>` headline is the series' first agent edit: its text and color are
  meant to be changed by your AI agent, on your machine, in front of you.

The repo is intentionally boring and locked: if history changes, the tutorial's
screenshots stop matching reality.
